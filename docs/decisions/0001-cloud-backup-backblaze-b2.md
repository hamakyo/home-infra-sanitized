# クラウド側の置き先に Backblaze B2 を選んだ

状態： 決定済み（バケット `backup-home-infra-example` 作成済み）

## 決定

NAS のオフサイトコピーの置き先は Backblaze B2。送信は restic（クライアント側暗号化）。

## 要件

- 誤BAN（正当な利用でのアカウント停止）のリスクが低いこと
- ロックインがないこと。置き先を替えても道具とデータ形式が変わらないこと

## 理由

- 料金は $6.95/TB/月 の従量制（2026-05 に $6 から改定）。ダウンロードは保存量の3倍まで無料、API コール無料
- S3 互換なので NAS の標準機能や restic から直接書ける
- Acceptable Use Policy が明文化されている。違反時も「可能な限り事前に通知し、是正の機会を与える」が原則で、即時停止は違法行為など重大な場合に限られる

## 落とした案

- **Hetzner Storage Box**：1TB 月 €3.20 と最安で、Borg / restic をネイティブに話せる。ただしアカウント停止や本人確認の却下について、説明が薄いまま止められたという報告が一貫して多い。誤BAN 回避を優先して落とした。なお報告の大半は VPS の話で、Storage Box は何も動かせない受動的な置き場所のため、リスクの質は同じではない
- **Cloudflare R2**：すでに利用中だが $15/TB/月 と割高
- **Wasabi**：$7.99/TB/月 で、最低保存期間の縛りがある

## 注意

- Backblaze の個人向け無制限バックアップ（Computer Backup）を NAS に使うのは規約で禁止されている。NAS の置き先は従量制の B2 が正規の使い方
- 耐性は事業者選びだけでなく設計でも作る。restic の暗号化コピーは内容を読まれないため内容ベースの誤判定が起きにくく、クラウド側は3コピーの1つでしかない
