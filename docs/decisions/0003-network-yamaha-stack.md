# 自宅ネットワーク刷新の候補に Yamaha（RTX830・SWX2210-8G・WLX222）を選んだ

状態： 候補選定（購入検討中（別リポジトリ管理・未購入））

## 決定

自宅ネットワークの将来刷新候補として、L3・L2・無線 AP を Yamaha の法人向け3台体制で揃える。

- **L3 ルーター**：Yamaha `RTX830`
- **L2 スイッチ**：Yamaha `SWX2210-8G`（スマート L2 / 1GbE×8 / ファンレス / 電源内蔵 / 非 PoE）
- **無線 AP**：Yamaha `WLX222`（Wi-Fi 6 / 2.5GbE×1 / マルチ SSID + 802.1Q タグ VLAN / RADIUS 内蔵）

## 要件

- 情シス・社内 SE の実務学習に直結する構成（L3 ルーティング・VLAN 分離・フィルタ・LAN マップ・テキストコンフィグ管理）であること
- ルーター設定をテキスト（SSH / CLI）で取り出して `example-user/home-infra-sanitized` で差分管理・AI 監査できること
- 居室に置ける静音性（ファンレス）があること
- 将来的に IoT 機器（スマート電球（IoT） ×3 など）とメイン端末を VLAN で分離できること
- 現行の 既設ホームルーター から一度に全置換せず、段階移行できること

## 理由

- **国内情シスの定番構成で学習効率が高い**：`RTX + SWX + WLX` の組み合わせは中小〜中堅企業の現場で広く使われており、構築・運用の知見がそのまま実務に活きる
- **LAN マップによる一括可視化と管理**：RTX830 を L2MS マネージャーにすることで、SWX2210-8G と WLX222、さらに配下の無線・有線端末までトポロジと稼働状態を一元把握できる
- **コンフィグのテキスト管理と監査性**：RTX830 は SSH 経由で `show config` を取得でき、git での履歴管理や AI による設定レビューと相性がよい
- **全機種ファンレス・高耐久**：3機種ともファンレス（動作周囲温度 0〜50℃）で居室置きに適している。RTX830 と SWX2210-8G は電源内蔵かつ横幅 220mm で揃う
- **SWX2210-8G の自立運用性**：単体で Web GUI を持ち、タグ VLAN（最大256）・ACL・SNMP・リンクアグリゲーションに対応するため、仮に将来ルーターを他社製へ替えても継続利用できる
- **WLX222 の認証・VLAN 機能**：マルチ SSID ごとの 802.1Q タグ VLAN に加え RADIUS サーバーを内蔵しており、WPA-Enterprise（802.1X）の検証まで AP 単体で完結できる
- **参考価格（参考・税込）**：
  - `RTX830`：希望小売 119,900円（実勢 約85,000〜95,000円）
  - `SWX2210-8G`：希望小売 55,000円（実勢 約38,000〜50,000円）
  - `WLX222`：希望小売 90,200円（実勢 約63,000〜81,000円）※AC アダプタ `YPS-12HT` は別売（希望小売 6,050円）

## 落とした案

- **既設ホームルーター の継続運用**：公式 API / SSH / CLI がなく、AP モードでのマルチ SSID タグ VLAN にも対応しないため、学習・監査・IoT 分離の要件を満たせない（移行途中の暫定 AP としては活用する）
- **MikroTik / OPNsense ルーター**：API・自動化やコスパでは有力だが、今回は国内情シス実務での定番である Yamaha CLI・LAN マップの習得を優先して見送った
- **Yamaha `SWX2110-8G`（シンプル L2）**：実勢 1.8〜2.5万円前後と安価だが、本体 Web GUI・ACL・SNMP・リンクアグリゲーションがなく AC アダプタ駆動のため、学習範囲と自立運用性を優先して `SWX2210-8G` を選んだ
- **Yamaha `SWX2310-10G`（インテリジェント L2）**：SSH・コンソールポート・802.1X 認証まで揃うファンレス機だが、自宅の初期構成としてはオーバースペックかつ筐体奥行き（250mm）が大きい
- **TP-Link `SG3210X-M2`（2.5GbE×8 + 10G SFP+×2）**：ファンレス・電源内蔵・SSH/CLI 対応で NAS のマルチギガ活用には有力だったが、Yamaha LAN マップでの一括管理と Yamaha 構成の学習を優先して今回は落とした（将来 2.5GbE 以上が必要になった場合の追加・置換候補として残す）
- **MikroTik `CRS310-8G+2S+IN`**：40mm 冷却ファン搭載で騒音が気になりやすく、居室置き前提に合わないため落とした
- **TP-Link Omada `EAP650`**：実売 2.3〜3万円前後・AC アダプタ付属でスタンドアロン 802.1Q タグ VLAN に対応しコスパは高いが、LAN マップ連携と内蔵 RADIUS での 802.1X 学習を優先して `WLX222` を候補とした

## 注意・制約

- **給電の注意**：`SWX2210-8G` は非 PoE で、`WLX222` には AC アダプタが同梱されない。購入時は純正 AC アダプタ `YPS-12HT` または PoE インジェクタ（例：`YPS-PoE-AT`）を必ず合わせて用意する（あるいはスイッチを PoE 対応機にする）
- **有線速度の上限（1GbE）**：`RTX830`・`SWX2210-8G` とも全ポート 1GbE のため、UGREEN NASync DXP4800 Plus（10GbE + 2.5GbE）と `workstation-01` の間を 2.5GbE 以上で繋ぎたくなった場合は別途マルチギガスイッチの併用を検討する
- **SWX2210-8G の CLI 制限**：CLI は Telnet のみ（SSH 非対応）。管理は RTX830 の LAN マップ経由または管理 VLAN 内に限定する
- **上流ルーター配下の二重 NAT**：上流がプライベート IP（`192.168.60.0/24`）のため、RTX830 側での外部向け VPN 着信は前提にしない。自宅外からのアクセスは引き続き Tailscale を本線とする
- **段階移行**：一度に全購入せず、`RTX830 + SWX2210-8G + 既設ホームルーター（AP モード）` で始め、無線 VLAN / 802.1X まで踏み込む段階で `WLX222` を導入できる
