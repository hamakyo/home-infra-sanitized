# NAS に UGREEN NASync DXP4800 Plus を選んだ

状態： 決定済み（ウィッシュリスト登録済み、未購入）

## 決定

自宅のファイルサーバーとして UGREEN NASync DXP4800 Plus を置く。
HDD は WD Red Plus 8TB（WD80EFPX）×4、RAID6 で実効 16TB。

## 要件

- 囲い込みやロックインがないこと
- NAS 自体に agent（Docker コンテナ）を常駐させられること
- 用途：GitHub repo のローカルミラー、Time Machine の受け先、写真とメディアの保管

## 理由

- ドライブの互換リストがなく、どのメーカーの HDD / NVMe も使える
- TrueNAS や Unraid への OS 入れ替えを公式が認めており、それでハードウェア保証が無効にならないと明言されている。ベンダー側の都合で使えなくなる道が塞がれている
- UGOS Pro に Docker と VM が入り、CPU は Pentium Gold 8505、メモリは 8GB から最大 64GB。agent 常駐に余裕がある
- 10GbE + 2.5GbE
- 価格：公式日本ストアで本体 ¥89,990（セール、定価 ¥105,880）

## 落とした案

- **Synology DS925+**：2025年4月に Plus 系を自社・認証ドライブのみに制限し、同年10月の DSM 7.3 で HDD については撤回した。ただし M.2 NVMe のプール作成は互換リスト必須のまま。方針が半年で往復した経緯を含め、「リストで縛る」発想が要件と衝突する
- **TerraMaster F4-424 Pro**：CPU（i3-N305）と 32GB メモリは最強だが、自社 OS の TOS が弱く TrueNAS への入れ替え前提の性格。日本の流通価格（楽天で ¥174,928）が米国公式価格（$688）の倍近くで割高だった
- **UGREEN DXP2800**：2ベイの入門機。RAID1 のみで拡張性が低く、置いて忘れる基盤には不足

## HDD の選定

- NAS 用途では CMR が前提（SMR は RAID リビルドで速度が崩壊する）
- WD Red Plus 8TB はツクモで ¥49,800、1TB あたり ¥6,225 で 4TB 版より割安
- 東芝 N300 は確認した店では割高で、7200rpm のため音と熱でも居室置きに不利だった
- Seagate IronWolf 8TB（¥52,280、データ復旧サービス3年付き）が僅差の次点
